```rust
fn main() {
    let input = "keyboard";
    let mut vowel_count = 0;
    let mut non_vowel_count = 0;

    for c in input.chars() {
        if ["a", "e", "i", "o", "u"].contains(&c.to_lowercase().as_str()) {
            vowel_count += 1;
        } else {
            non_vowel_count += 1;
        }
    }

    println!("Vowels: {}", vowel_count);
    println!("Non-vowels: {}", non_vowel_count);
}
```
This program takes a string input from the user, iterates through each character, and counts how many characters are vowels (both uppercase and lowercase) and non-vowels. It then prints out the counts for both categories.
