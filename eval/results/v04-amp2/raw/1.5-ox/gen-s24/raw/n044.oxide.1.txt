```rust
fn main() {
    let mut balance = 0;
    for deposit in vec![3, 1, 4, 1, 5] {
        balance += deposit;
        println!("Balance: {}", balance);
    }
}
```

This program initializes a mutable variable `balance` to zero and then iterates over the vector of deposits. For each deposit, it adds the deposit amount to `balance`, prints the updated balance, and continues with the next deposit.
