```rust
fn main() {
    let texts = vec![7, None, 9, None];
    let mut sum = 0;
    let mut count = 0;

    for &text in &texts {
        if text.is_some() {
            sum += text.unwrap();
            count += 1;
        }
    }

    println!("Sum of numbers: {}", sum);
    println!("Count of non-number texts: {}", count);
}
```

Explanation:
- The `main` function initializes a vector `texts` containing the given elements.
- It uses a `for` loop to iterate over each element in the `texts` vector.
- For each element, it checks if it is `Some` (i.e., contains a value).
- If an element is `Some`, it adds its value to `sum` and increments `count`.
- After the loop completes, it prints the total of numbers (`sum`) and the count of non-number texts (`count`).
