```rust
fn divide(a: f64, b: f64) -> Result<f64, &'static str> {
    if b == 0.0 {
        Err("Cannot divide by zero")
    } else {
        Ok(a / b)
    }
}

fn main() {
    match divide(20.0, 4.0) {
        Ok(result) => println!("The result is {}", result),
        Err(e) => println!("{}", e),
    }
}
```

This Rust program defines a function `divide` that takes two f64 values and attempts to divide them. If the second value is zero, it returns an error message. Otherwise, it returns the result as a Ok. In the main function, it calls `divide` with 20.0 and 4.0, prints the result, or the error message if the division fails.
