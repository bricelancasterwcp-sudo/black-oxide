```rust
struct Queue(Vec<Int>);

impl Queue {
    fn new(v: Vec<Int>) -> Queue { Queue(v) }

    fn exchange(&mut self) {
        let len = self.0.len();
        if len > 1 {
            let tmp = self.0[0];
            self.0[0] = self.0[len - 1];
            self.0[len - 1] = tmp;
        }
    }
}

fn main() {
    let mut q = Queue(vec![1, 2, 3, 4, 5]);
    q.exchange();
    for &x in q.0.iter() {
        print!("{}", x);
    }
}
```

This program uses the `Queue` struct to hold the queue elements and a method `exchange` to swap the first and last elements of the queue. The main function creates a `Queue` with the specified elements, exchanges them, and prints each element on a new line.
