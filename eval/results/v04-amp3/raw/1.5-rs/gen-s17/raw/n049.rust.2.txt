```rust
fn main() {
    let numbers = [8, 3, 11, 6];
    let min_number = *numbers.iter().min().unwrap();
    let max_number = *numbers.iter().max().unwrap();

    println!("Smallest figure: {}", min_number);
    println!("Gap between the largest and smallest: {}", max_number - min_number);
}
```

This program calculates the minimum and maximum values in a slice of integers, then prints them along with the gap between them. The `unwrap()` method is used to safely extract the values from the iterator returned by `min()`, since these methods return references to the smallest and largest elements in the sequence, not their actual values.
