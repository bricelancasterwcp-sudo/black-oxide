```rust
fn main() {
    let phrase = "when in doubt go home";
    let word_count = phrase.split_whitespace().count();
    let char_count = phrase.len();
    
    println!("Word count: {}", word_count);
    println!("Character count (including spaces): {}", char_count);
}
```

When you run this program, it prints:
```
Word count: 4
Character count (including spaces): 19
```
