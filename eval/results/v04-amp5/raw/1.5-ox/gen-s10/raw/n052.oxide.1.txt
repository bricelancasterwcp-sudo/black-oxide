```rust
fn main() {
    let banana = "banana";
    for i in 0..banana.len() {
        if banana.chars().nth(i) == Some('n') {
            println!("{}", i);
        }
    }
}
```

This program defines a `main` function that takes the string `"banana"` as input. It then iterates over each character in the string using a for loop, starting from index 0 and ending at the length of the string minus one. Inside the loop, it checks if the current character is 'n' using the `chars().nth(i)` method. If it is, it prints out the position (i.e., the index) of the character on a new line using `println!`.
