```rust
struct Reading { label: Str, values: Vec<Int> }

fn main() {
    let mut r = Reading { label: "lab", values: vec![0] };
    r.values[0] = 7;
    print(r.values[0]);
}
```

Note that the `push` function in Rust consumes its argument and returns a new vector with the added element. Since `r.values` is already consumed by `push`, we need to reassign it before modifying it further.
