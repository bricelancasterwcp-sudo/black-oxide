```rust
fn main() {
    let mut balance = 0;
    
    balance += 3; // Deposit 3
    println!("Balance: {}", balance);
    
    balance -= 1; // Withdrawal 1
    println!("Balance: {}", balance);
    
    balance += 4; // Deposit 4
    println!("Balance: {}", balance);
    
    balance -= 1; // Withdrawal 1
    println!("Balance: {}", balance);
    
    balance += 5; // Deposit 5
    println!("Balance: {}", balance);
}
```
This Rust program starts with a balance of zero. It then deposits three units, withdraws one unit, deposits four units, withdraws one unit again, and finally deposits five units. The balance after each deposit or withdrawal is printed to the console.
