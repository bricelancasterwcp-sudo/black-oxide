```rust
struct Rectangle { width: Int, height: Int }

fn change_width(rect: &mut Rectangle, new_width: Int) {
    rect.width = new_width;
}

fn main() {
    let mut r = Rectangle { width: 2, height: 3 };
    change_width(&mut r, 5);
    print(r.area());
}
```
In this program, we define a `Rectangle` struct with two fields: `width` and `height`. The `change_width` function takes a mutable reference to a `Rectangle` and a new width value. Inside the function, it directly assigns the new width value to the `width` field of the rectangle using the dot notation.

In the `main` function, we create an instance of `Rectangle`, change its width to 5 by calling `change_width`, and then print the area of the rectangle by accessing the `area` method.
