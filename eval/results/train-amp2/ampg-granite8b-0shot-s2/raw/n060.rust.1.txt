```rust
fn main() {
    let text = "a1b22";
    let mut digit_count = 0;
    let mut digit_total = 0;
    for c in text.chars() {
        if c.is_ascii_digit() {
            digit_count += 1;
            digit_total += c.to_digit(10).unwrap() as usize;
        }
    }
    println!("digit count: {}", digit_count);
    println!("digit total: {}", digit_total);
}
```

This solution uses a for loop to iterate over each character in the input string. It checks if the character is a digit using the is_ascii_digit() method. If the character is a digit, it increments the digit_count and adds the value of the digit to the digit_total. Finally, it prints the results.
