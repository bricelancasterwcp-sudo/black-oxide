```rust
fn main() {
    let mut text = String::new();
    text.push_str("one");
    text.push_str("two");
    text.push_str("three");
    println!("{}", text);
}
```

This code initializes an empty string `text` and then appends the strings "one", "two", and "three" to it using the `push_str` method. Finally, it prints the resulting string using `println!`.
