```rust
fn main() {
    let mut input = vec!["8", "oak", "15"];
    
    for i in &input {
        if i.is_empty() {
            println!("bad");
        } else {
            println!("{}", i);
        }
    }
}
```

In this Rust program, we declare a mutable vector `input` containing the three strings: "8", "oak", and "15". Then, we iterate through each string in `input` using a for loop. Inside the loop, we check if the string is empty using the `is_empty()` method. If it is, we print "bad"; otherwise, we print the number by printing the string itself.
