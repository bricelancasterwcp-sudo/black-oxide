```rust
fn main() {
    let mut count = 0;
    for n in 1..=36 {
        if 36 % n == 0 {
            count += 1;
        }
    }
    print(count);
}
```

The program initializes a counter to zero, then iterates over the range from 1 to 36 (inclusive). Inside the loop, it checks if `n` is a divisor of 36 using the modulo operator `%`. If so, it increments the counter. Finally, it prints the value of the counter.
