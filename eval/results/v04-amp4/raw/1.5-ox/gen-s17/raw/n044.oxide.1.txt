```rust
fn main() {
    let mut balance = 0;
    for deposit in vec![3, 1, 4, 1, 5] {
        balance += deposit;
        println!("{}", balance);
    }
}
```

In this code:
- The `main` function initializes a variable `balance` to zero.
- It then iterates over the vector `[3, 1, 4, 1, 5]`.
- In each iteration, it adds the current deposit value to `balance`.
- After adding the deposit to `balance`, it prints the new balance using `{}` to format the integer as a string and print it.
- The loop continues until all deposits have been processed.
