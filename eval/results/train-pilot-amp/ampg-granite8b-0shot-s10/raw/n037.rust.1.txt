```rust
fn main() {
    let mut width = 2;
    let mut height = 3;

    width = 5;

    println!("The area of the rectangle is {} square pixels.", width * height);
}
```

Note that in Rust, you do not need to declare the type of a variable. Rust infers the type of a variable based on the value assigned to it. In this case, we initialize `width` and `height` as `u32` (unsigned 32-bit integer) values, but the compiler can infer that `width` should be a `u32` because we assign it a value of `2`. Similarly, the compiler can infer that `height` should be a `u32` because we assign it a value of `3`.
