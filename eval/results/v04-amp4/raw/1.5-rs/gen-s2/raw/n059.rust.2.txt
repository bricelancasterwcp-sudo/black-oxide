```rust
fn main() {
    let phrase = "when in doubt go home";
    let words_count = phrase.split_whitespace().count();
    let char_count = phrase.len();

    println!("The phrase contains {} words and spans {} characters.", words_count, char_count);
}
```
Explanation:
In the provided code, `split_whitespace()` was used to split the string into a vector of words. The count function was then used on this vector to find out how many words there are, which is stored in the variable `words_count`. However, instead of directly using this value in the print statement, it's printed as if it were the total number of characters (`phrase.len()`). This resulted in the incorrect output. To fix this, we simply substitute `phrase.len()` with `char_count` in the print statement to get the correct result.
