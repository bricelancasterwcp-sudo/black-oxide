```rust
fn main() {
    let mut v = push(push(vec(), 1), 2);
    print(len(v));
    for x in &mut v {
        v = push(v, *x);
    }
    print(len(v));
}
```

Explanation:
- The loop is iterating the vector `v` by reference (`&mut v`). This allows us to modify the vector inside the loop without consuming it.
- After the loop, we reassign `v` with the modified version.
