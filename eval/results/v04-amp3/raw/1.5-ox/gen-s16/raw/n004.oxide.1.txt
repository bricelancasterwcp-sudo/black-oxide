```rust
fn main() {
    let mut a = 1;
    let mut b = 1;

    for _ in 2..=9 {
        let c = a + b;
        a = b;
        b = c;
    }

    print(a);
}
```
The code initializes two variables `a` and `b` to 1, then iterates from 2 to 9. In each iteration, it calculates the sum of `a` and `b`, assigns this result to `c`, and then updates `a` and `b` to be `b` and `c` respectively. After the loop finishes, `a` will contain the tenth term of the sequence (14).
