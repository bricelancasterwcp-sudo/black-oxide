# sha256 ledger for the fine-tune artifacts every v0.4 wave's numbers rest on.
#
# WHY THIS FILE IS IN THE REPO. The artifacts themselves live outside it, in
# ~/workspace/oxide-runpod-artifacts/, which is not version-controlled and
# not backed up. The hashes are small, so they can live with the record they
# authenticate. Copied verbatim from that directory's SHAS.txt; the hash
# lines below are byte-identical to it so `sha256sum -c` accepts them.
#
# EACH NON-COMMENT LINE is `<sha256>  <path>` in sha256sum's own text format
# (two spaces). Two kinds of line, and they are not preserved the same way:
#
#   /workspace/gguf/*.gguf   POD-BUILT merged + q8_0-quantised models, hashed
#                            on the pod at /workspace/gguf/. NOT preserved
#                            locally: each is 8-16 GB and each is a pure
#                            function of a base checkpoint and an adapter, so
#                            every wave rebuilds the ones it needs from the
#                            adapters (scripts/runpod/merge_lora.py, then
#                            convert_quant.sh). These lines exist to prove a
#                            rebuild reproduced the model a wave actually
#                            served -- wave 8's Phase B confirmed the base
#                            7B GGUF byte-identical across pods this way.
#
#   adapters-v*/...          THE LoRA ADAPTERS, which ARE preserved locally.
#                            A few MB each, and not reproducible: retraining
#                            costs GPU time and would not land byte-identical
#                            anyway. If these are lost, every v0.4 dynamic
#                            number becomes unreproducible.
#
# LOCAL PATH CONVENTION. The adapter paths are relative to the wave directory
# that produced them, not to the artifacts root:
#
#   ~/workspace/oxide-runpod-artifacts/wave2/adapters-v3/<arm>/adapter_model.safetensors
#   ~/workspace/oxide-runpod-artifacts/wave3/adapters-v4/<arm>/adapter_model.safetensors
#   ~/workspace/oxide-runpod-artifacts/wave4/adapters-v5/<arm>/adapter_model.safetensors
#
# So a check runs from the wave directory, over that wave's lines only:
#
#   cd ~/workspace/oxide-runpod-artifacts/wave4 \
#     && grep -E '^[0-9a-f]{64}  adapters-v5/' <this file> | sha256sum -c
#
# All four v5 adapters (7B and 14B, both arms) verified this way 2026-09-02,
# along with the v3 and v4 pairs: 8 of 8 OK. The /workspace/gguf/ lines
# cannot be checked locally -- those files were never transferred.
#
