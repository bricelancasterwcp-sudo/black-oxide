```rust
fn main() {
    let mut count = 0;
    for i in 1..=36 {
        if 36 % i == 0 {
            count += 1;
        }
    }
    print(count);
}
```

Explanation:
- We initialize a counter `count` to zero.
- We use a `for` loop to iterate over the numbers from 1 to 36 (inclusive).
- Inside the loop, we check if the current number `i` divides 36 exactly using the modulus operator `%`.
- If it does, we increment the `count` by 1.
- Finally, we print the value of `count`, which represents the count of whole numbers from 1 to 36 that divide 36 exactly.
