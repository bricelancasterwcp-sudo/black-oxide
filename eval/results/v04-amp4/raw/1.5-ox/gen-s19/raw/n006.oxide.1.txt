```rust
fn main() {
    let mut biggest = 0;
    for i in 0..=9 {
        if 2i.pow(i) > 100 {
            break;
        }
        biggest = i;
    }
    print(biggest);
}
```

Explanation:
- We initialize `biggest` to 0.
- We use a `for` loop to iterate through the powers of 2 from 0 to 9 (inclusive).
- If `2i.pow(i)` exceeds 100, we break out of the loop because the next power will be larger than 100.
- Once the loop is broken, `biggest` holds the largest power of two that does not exceed 100. We then print this value using `print`.
