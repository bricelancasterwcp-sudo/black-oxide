```rust
fn main() {
    let mut count_vowels = 0;
    let mut count_not_vowels = 0;

    // Loop through each letter in the word "keyboard"
    for letter in "keyboard".chars() {
        match letter.to_ascii_lowercase() {
            'a' | 'e' | 'i' | 'o' | 'u' => count_vowels += 1,
            _ => count_not_vowels += 1,
        }
    }

    // Print the counts
    println!("Vowels: {}", count_vowels);
    println!("Not vowels: {}", count_not_vowels);
}
```

This Rust program defines a function `main` that goes through each letter in the word "keyboard" and uses a `match` statement to check if each character is a vowel (either lowercase 'a', 'e', 'i', 'o', or 'u'). If it is a vowel, the count for vowels is incremented; otherwise, the count for not-vowels is incremented. Finally, the program prints out the counts of vowels and not-vowels.
