```rust
fn main() {
    let text = "banana";
    for (index, char) in text.chars().enumerate() {
        if char == 'n' {
            println!("{}", index);
        }
    }
}
```

This Rust program iterates over each character in the string `"banana"`, counting from zero. If a character is `'n'`, it prints the current index on a new line.
