```rust
fn main() {
    let total = 0;
    let count = 0;
    for c in a1b22.chars() {
        if c.is_digit(10) {
            total += c.to_digit(10).unwrap();
            count += 1;
        }
    }
    println!("Total: {}", total);
    println!("Count: {}", count);
}
```

The program iterates over each character in the string `a1b22`. It checks if a character is a digit using the `is_digit` method. If it is, the program converts the character to an integer using `to_digit(10)`, adds it to the total sum, and increments the count of digits. After processing all characters, the program prints the total sum and the count of digits.
