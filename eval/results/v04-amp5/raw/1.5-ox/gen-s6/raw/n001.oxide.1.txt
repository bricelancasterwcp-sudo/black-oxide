```rust
fn cube(x: Int) -> Int {
    x * x * x
}

fn main() {
    let sum = (1..=5).map(|i| cube(i)).sum();
    println!("{}", sum);
}
```

Explanation:
- The `cube` function calculates the cube of a given integer `x`.
- In the `main` function, we use the `map` method to apply the `cube` function to each number from 1 to 5. This creates a vector of cubes.
- We then use the `sum` method on the resulting vector to calculate the total sum of these cubes.
- Finally, we print the sum using `println!`.
