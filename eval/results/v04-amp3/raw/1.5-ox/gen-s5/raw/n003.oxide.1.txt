```rust
fn main() {
    let mut count = 0;
    for i in 1..=36 {
        if 36 % i == 0 {
            count += 1;
        }
    }
    print(count);
}
```

The program uses a simple loop to iterate from 1 to 36, checks each number to see if it divides 36 exactly with no remainder (i.e., `36 % i == 0`), and increments the `count` variable for each divisor. Finally, it prints out the count of such divisors.
