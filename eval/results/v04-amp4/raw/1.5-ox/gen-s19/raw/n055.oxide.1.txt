```rust
fn main() {
    for item in vec![8, "oak", 15] {
        if let Int(x) = item {
            print(x);
        } else {
            print_str("bad");
        }
    }
}
```

This program iterates over a vector containing integers, strings, and floats. It uses pattern matching (`if let`) to check if each item can be converted into an `Int`. If it can, it prints the integer value; otherwise, it prints "bad".
