```rust
fn main() {
    let num = 91;
    if num > 1 && (num % 2 == 0 || num % 3 == 0) {
        println!("no");
    } else {
        println!("yes");
    }
}
```

In this program, we first declare the variable `num` and assign it the value 91. We then check if `num` is greater than 1 because a number less than or equal to 1 is not prime. Next, we use an `if-else` statement to check if `num` is divisible by 2 or 3 without a remainder (`num % 2 == 0 || num % 3 == 0`). If either condition is true, we print "no", indicating that the number is not prime. Otherwise, we print "yes".
