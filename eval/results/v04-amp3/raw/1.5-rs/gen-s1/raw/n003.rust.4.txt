Here's the complete corrected Rust (edition 2021), std only, no external crates. It counts how many whole numbers from 1 to 36 divide 36 exactly and prints the count.

```rust
fn main() {
    let mut count = 0;

    for num in 1..=36 {
        if num % 36 == 0 {
            count += 1;
        }
    }

    println!("Count: {}", count);
}
```
