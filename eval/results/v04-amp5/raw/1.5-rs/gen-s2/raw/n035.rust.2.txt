```rust
fn divide(a: i32, b: i32) -> Result<f64, &'static str> {
    if b == 0 {
        Err("Divide by zero")
    } else {
        Ok(a as f64 / b as f64)
    }
}

fn main() {
    match divide(20, 4) {
        Ok(result) => println!("{} / {} = {}", 20, 4, result),
        Err(msg) => println!("{}", msg),
    }
}
```
The error was caused by the fact that when `divide` returns an `Err` value, it does not automatically print the message. The solution is to add a match arm for the Err case in main and print the message there.
