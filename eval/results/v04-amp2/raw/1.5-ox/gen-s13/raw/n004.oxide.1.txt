```rust
fn main() {
    let mut a = 1;
    let mut b = 1;

    for _ in 0..9 {
        let c = a + b;
        a = b;
        b = c;
    }

    print(a);
}
```

This program calculates the tenth term of the Fibonacci sequence, where each term is the sum of the two preceding ones. It initializes `a` and `b` to 1, then iterates 9 times (since the first two terms are already given), updating `a` and `b` in each iteration to compute the next term. Finally, it prints the tenth term.
