```rust
fn main() {
    let mut count = 0;
    for i in 1..=36 {
        if 36 % i == 0 {
            count += 1;
        }
    }
    print(count);
}
```

The program defines a `main` function that initializes a counter to zero. It then iterates over the range from 1 to 36, checking if each number divides 36 exactly using the modulus operator (`%`). If a number divides 36, it increments the counter. Finally, it prints the count of whole numbers from 1 to 36 that divide 36 exactly.
