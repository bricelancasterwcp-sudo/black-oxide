```rust
fn main() {
    match &[8, "oak", 15] {
        [x, y, z] => {
            println!("{}", x);
            println!("{}", y);
            println!("{}", z);
        }
        _ => println!("bad")
    }
}
```
In this program, we use pattern matching to unpack an array into three values. The `match` statement checks if the array contains exactly three elements, and in that case, it prints each element. If there are fewer or more than three elements, it prints "bad".
