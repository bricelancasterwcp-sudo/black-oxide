```rust
fn main() {
    let mut count = 0;
    for i in 1..=36 {
        if 36 % i == 0 {
            count += 1;
        }
    }
    print(count);
}
```

This program counts how many whole numbers from 1 to 36 divide 36 exactly and prints the result. It initializes a counter at 0, then iterates through each number from 1 to 36. If a number `i` divides 36 (checked with `if 36 % i == 0`), it increments the counter. Finally, it prints the value of the counter, which represents how many whole numbers divide 36 exactly.
