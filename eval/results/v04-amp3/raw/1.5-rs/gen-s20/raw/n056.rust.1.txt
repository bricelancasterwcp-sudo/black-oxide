```rust
fn main() {
    let texts = ["7", "x", "9", "?"];

    let mut sum = 0;
    let mut count_not = 0;

    for &text in texts.iter() {
        if text.chars().any(|c| c.is_numeric()) {
            sum += text.parse::<u32>().unwrap();
        } else {
            count_not += 1;
        }
    }

    println!("The total of the ones that do is: {}", sum);
    println!("How many do not is: {}", count_not);
}
```

This Rust program initializes a vector with four strings. It then iterates over each string, checking if it contains any digits using `chars().any(|c| c.is_numeric())`. If a number is found, it parses the string into an integer and adds it to `sum`. If no digit is found (i.e., the string does not contain a number), it increments `count_not`. Finally, it prints out the total sum of the numbers and the count of strings that do not contain any digits.
