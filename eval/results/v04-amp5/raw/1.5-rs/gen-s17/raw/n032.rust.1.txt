```rust
fn main() {
    let p1 = (1, 5);
    let p2 = (10, 5);

    println!("{}", p1.0 + p2.0);
}
```

This Rust code defines a main function which creates two tuples representing points (x, y), where the point at one across and five up is represented as `(1, 5)`, and the point with the same height but ten across is represented as `(10, 5)`. The program then prints the sum of the x-coordinates of the two points.
