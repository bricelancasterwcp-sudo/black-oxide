```rust
fn main() {
    let mut count = 0;
    for n in 1..=36 {
        if 36 % n == 0 {
            count += 1;
        }
    }
    print(count);
}
```

This program uses a `for` loop to iterate from 1 to 36, checking each number if it divides 36 exactly using the modulus operator (`%`). If true, it increments the counter. After the loop completes, the final count is printed.
