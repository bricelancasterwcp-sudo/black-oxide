```rust
fn main() {
    let word = "coffee";
    let mut seen = std::collections::HashSet::new();

    for c in word.chars() {
        if !seen.contains(&c) {
            println!("{}", c);
            seen.insert(c);
        }
    }
}
```

This program declares a string constant `word` containing the coffee word. It then creates an empty `HashSet` to keep track of letters that have been encountered. The program iterates over each character in the word, and if the letter has not yet been added to the set (i.e., it is not already in the hash), it prints the letter and inserts it into the set.
