```rust
fn main() {
    let mut sum = 0;
    for i in 1..=20 {
        if i % 2 == 0 {
            sum += i;
        }
    }
    println!("Total of all even numbers between 1 and 20 inclusive: {}", sum);
}
```

Explanation:
The output "110" is correct, as the sum of all even numbers from 1 to 20 is indeed 110.
