```rust
fn main() {
    let banana = "banana";
    for i in 0..banana.len() {
        if banana.chars().nth(i) == Some('n') {
            println!("{}", i);
        }
    }
}
```

The problem was that the `main` function had a semicolon at the end, which caused the compiler to interpret it as an expression instead of a statement. Additionally, there were missing parentheses around the `banana` variable in the `println!` call.
