```rust
fn second_entry(v: Vec<Int>) -> Option<&Int> {
    v.get(1)
}

fn main() {
    let vecs = vec![7, 8, 9];
    println!("{:?}", second_entry(vecs)); // prints Some(&8)
}
```

This program defines a function `second_entry` that takes a vector of integers and returns an optional reference to the second element. If there are fewer than two elements in the vector, it returns `None`. In the `main` function, it creates a vector `[7, 8, 9]`, calls `second_entry` with this vector, and prints the result.
