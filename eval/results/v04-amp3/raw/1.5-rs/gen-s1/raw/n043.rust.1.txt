```rust
fn main() {
    let mut q = vec![1, 2, 3, 4, 5];
    std::mem::swap(&mut q[0], &mut q[q.len() - 1]);
    for num in q {
        println!("{}", num);
    }
}
```

This Rust program declares a mutable vector `q` containing the numbers 1 through 5. It uses `std::mem::swap()` to exchange the first and last elements of the vector. Finally, it iterates over the modified vector and prints each element on a new line.
