```rust
fn main() {
    let samples = [5, 12, 3, 18, 9];
    let cutoff = 10;

    let mut below_cutoff = 0;
    let mut above_or_equal_cutoff = 0;

    for &sample in &samples {
        if sample < cutoff {
            below_cutoff += 1;
        } else {
            above_or_equal_cutoff += 1;
        }
    }

    println!("Below the cutoff: {}", below_cutoff);
    println!("Above or equal to the cutoff: {}", above_or_equal_cutoff);
}
```

In this program, we define an array `samples` containing the given numbers and a variable `cutoff` with the specified value. We initialize two counters `below_cutoff` and `above_or_equal_cutoff` to zero. Then, we iterate over each element in the `samples` array using a for loop. For each sample, we check if it is less than the cutoff value. If it is, we increment the `below_cutoff` counter; otherwise, we increment the `above_or_equal_cutoff` counter. Finally, we print the counts of numbers below and above or equal to the cutoff.
