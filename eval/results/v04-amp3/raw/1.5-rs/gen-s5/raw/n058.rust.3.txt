```rust
fn main() {
    let mut freq_map = [0; 26];
    let word = "coffee";
    for ch in word.chars() {
        let idx = (ch as u8 - b'a') as usize;
        freq_map[idx] += 1;
    }

    for &freq in freq_map.iter().filter(|&&f| f > 0) {
        print!("{}\n", char::from(b'a' + freq - 1));
    }
}
```

The original program was using `filter` with `as usize`, which might have caused unexpected behavior due to the potential overflow of `u8`. By subtracting `b'a'` first and then casting to `usize`, we avoid the potential for overflow. This ensures that each letter's frequency is correctly calculated and printed in the desired order.
