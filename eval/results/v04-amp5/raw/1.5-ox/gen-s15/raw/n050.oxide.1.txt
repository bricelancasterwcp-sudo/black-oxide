```rust
fn main() {
    let scores = vec![5, 9, 2];
    scores.sort_unstable_by(|a, b| b.cmp(a));
    for &score in &scores {
        print!("{}", score);
        println!();
    }
}
```

This program sorts the `scores` vector in descending order and then prints each element. The `sort_unstable_by` function is used to sort the vector without changing the original order, ensuring that ties are handled correctly.
