```rust
fn main() {
    let text = "banana";
    for (i, &c) in text.chars().enumerate() {
        if c == 'n' {
            println!("{}", i);
        }
    }
}
```

This Rust program iterates over each character `c` and its index `i` in the string `"banana"`. When it finds a 'n', it prints that index.
