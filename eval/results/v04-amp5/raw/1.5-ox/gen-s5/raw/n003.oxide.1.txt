```rust
fn main() {
    let mut count = 0;
    for i in 1..=36 {
        if 36 % i == 0 {
            count += 1;
        }
    }
    print(count);
}
```

Explanation:
- We start by initializing a mutable counter variable `count` to zero.
- We then use a loop to iterate through numbers from 1 to 36 (inclusive).
- Inside the loop, we check if `i` is exactly divisible by 36 using the modulo operator (`%`). If it is, we increment the `count`.
- After the loop completes, we print the final value of `count`.
