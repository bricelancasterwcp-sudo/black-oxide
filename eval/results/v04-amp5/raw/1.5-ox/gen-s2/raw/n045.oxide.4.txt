```rust
struct Log { entries: Vec<Int> }

fn main() {
    let log = Log { entries: vec![6, 7, 8, 9] };
    println!("{}", log.entries[0]);
    println!("{}", log.entries[last_index(&log.entries)]);
}
```

Note: The correct way to access the last element in a vector is using `last_index`, not `len` and subscripting.
