```rust
struct Log { entries: [Int; 4] }

fn first_entry(log: &Log) -> Int {
    log.entries[0]
}

fn last_entry(log: &Log) -> Int {
    log.entries[3]
}

fn main() {
    let mut log = Log { entries: [6, 7, 8, 9] };
    print(first_entry(&log));            // field access copies: r stays usable
    print(last_entry(&log));
}
```

This program declares a `Log` struct with an array of Int values and provides functions to get the first and last entries. The `main` function then creates a Log instance, uses these functions to print the first and last entries, and prints them.
