```rust
fn main() {
    let mut v = vec!(10, 20);
    println!("{:?}", get(v, 0));
    println!("{:?}", get(v, 3));
}
```
This program defines a vector `v` containing the numbers 10 and 20. It uses the `get` function to retrieve and print the values at positions 0 and 3 in the vector. Since the vector has only two elements, the value at position 3 (`None`) is printed as "None".
