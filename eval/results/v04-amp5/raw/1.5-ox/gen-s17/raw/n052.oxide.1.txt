```rust
fn main() {
    let banana = "banana";
    for (i, c) in banana.chars().enumerate() {
        if c == 'n' {
            print!("{:?}", i);
        }
    }
}
```

This program iterates over each character in the string `banana` and prints its position (`i`) whenever it encounters the letter 'n'. The `{:?}", i}` format specifier is used to print the index, which starts from zero.
