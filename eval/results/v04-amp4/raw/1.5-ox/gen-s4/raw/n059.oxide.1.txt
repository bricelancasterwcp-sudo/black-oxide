```rust
fn main() {
    let s = "when in doubt go home";
    let words = s.split_whitespace().count();
    println!("The phrase contains {} words", words);
    let chars = s.chars().count();
    println!("It spans {} characters including spaces", chars);
}
```

In this program, we first split the input string `s` into an iterator of words using the `split_whitespace()` method. We then count these words with `.count()`, which returns the number of elements in the iterator. The total number of characters, including spaces between words, is calculated by counting the characters in the character iterator generated by `chars()`. Finally, we print both counts.
