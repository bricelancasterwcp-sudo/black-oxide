```rust
fn main() {
    let mut count = 0;
    for i in 1..=36 {
        if 36 % i == 0 {
            count += 1;
        }
    }
    print(count);
}
```

The error was due to the use of semicolons at the end of each line. In Rust, newlines end statements and blocks `{ }` are expressions; the last expression in a block is its value (no `return` needed at the end). So removing the semicolons fixed the syntax issues.
