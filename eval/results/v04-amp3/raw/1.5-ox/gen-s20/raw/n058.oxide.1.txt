```rust
fn main() {
    let word = "coffee";
    let mut seen = Vec::new();

    for c in word.chars() {
        if !seen.contains(&c) {
            println!("{}", c);
            seen.push(c);
        }
    }
}
```

This program prints each unique letter from the word "coffee" exactly once, in the order it first appears. It uses a `Vec` to keep track of which letters have been encountered, ensuring that each letter is printed only once and in the correct order.
