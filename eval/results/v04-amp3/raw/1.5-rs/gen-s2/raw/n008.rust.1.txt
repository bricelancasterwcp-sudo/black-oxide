```rust
fn main() {
    let mut count = 0;
    for i in 1..=50 {
        if i % 3 == 0 || i % 5 == 0 {
            count += 1;
        }
    }
    println!("Count: {}", count);
}
```

This Rust program defines a `main` function where it iterates from 1 to 50, checking each number to see if it is divisible by 3 or 5. If so, it increments the `count`. Finally, it prints out the total count of numbers that satisfy the condition.
