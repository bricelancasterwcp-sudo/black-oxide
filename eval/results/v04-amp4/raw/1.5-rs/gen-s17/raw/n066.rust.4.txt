```rust
fn main() {
    let numbers = [9, 2, 12, 5, 16];
    let mut count = 0;

    for &number in &numbers {
        if number < 10 {
            println!("{}", number);
            count += 1;
        }
    }

    println!("Number of entries kept: {}", count);
}
```

This program successfully keeps every entry under ten from the given array and prints each kept entry on its own line. It then counts and displays how many entries were kept. The output remains as expected:
```
9
2
5
Number of entries kept: 3
```
