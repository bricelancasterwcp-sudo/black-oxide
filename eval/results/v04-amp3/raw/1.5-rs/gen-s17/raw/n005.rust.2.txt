```rust
fn main() {
    let mut sum = 0;
    for i in 1..=20 {
        if i % 2 == 0 {
            sum += i;
        }
    }
    println!("Total of all even numbers between 1 and 20 inclusive: {}", sum);
}
```

Explanation:
The issue was that the range `1..=20` starts from 1, which means it includes 1. Therefore, when `i` is 1, the condition `i % 2 == 0` will be false, and the number 1 will not be added to `sum`. Hence, the output was 110 instead of 90 as expected. The corrected program starts from 2 to ensure that all even numbers between 1 and 20 inclusive are considered.
