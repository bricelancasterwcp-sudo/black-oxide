```rust
fn main() {
    let numbers = vec![7, 8, 9];
    match numbers.get(1) {
        Some(&second_entry) => println!("Second entry: {}", second_entry),
        None => println!("No second entry found."),
    }
}
```

When you run this program with the input `vec![7, 8, 9]`, it will print "Second entry: 8".
