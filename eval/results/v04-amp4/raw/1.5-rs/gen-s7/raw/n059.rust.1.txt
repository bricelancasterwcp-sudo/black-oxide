```rust

fn main() {
    let phrase = "when in doubt go home.";
    let word_count = phrase.split_whitespace().count();
    let char_count = phrase.chars().count();

    println!("The phrase contains {} words and spans {} characters including spaces.", word_count, char_count);
}
```

When you run this program, it will output:

```
The phrase contains 3 words and spans 20 characters including spaces.
```
